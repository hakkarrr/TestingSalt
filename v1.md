## Task 1.4 — CSS Custom Properties (Theming Prep)

**Goal:** Replace every hardcoded color with CSS variables so you can toggle themes later.

**Action Steps:**

1. At the top of `styles.css`, create a `:root` block:
```css
:root {
    --bg-primary: #0b0b0b;
    --bg-secondary: #1a1a1a;
    --bg-header: #2a2a2a;
    --bg-input: #1f1f1f;
    --bg-input-field: #2a2a2a;
    --bg-bubble-sent: #005c4b;
    --bg-bubble-received: #262626;
    --text-primary: #ffffff;
    --text-secondary: #e1e1e1;
    --text-muted: #888888;
    --border-color: #2f2f2f;
    --accent: #005c4b;
    --online-dot: #31a24c;
}
```

2. Replace **every** hardcoded hex color in your CSS with `var(--variable-name)`.
   - Example: `background: #1a1a1a;` → `background: var(--bg-secondary);`

3. Do a final check: Search your `styles.css` for `#` — there should be **zero** remaining hex codes except inside the `:root` block.

**Verification (MANDATORY):**
- [ ] App looks **exactly the same** as before (no visual changes).
- [ ] Changing a variable (e.g., `--bg-secondary: red;`) instantly changes that part of the UI.
- [ ] No hardcoded hex codes remain outside `:root`.

**If this fails →** Use Ctrl+F to find all `#` and replace missed colors.  
**If this passes →** Proceed to Task 1.5.

## Task 1.5 — Mobile Responsiveness (CSS Contract)

**Goal:** Define the CSS for a slide-in sidebar that will be activated by JavaScript later. For now, you just need the CSS to exist and be manually toggleable.

**Action Steps:**

1. In your HTML, add a hamburger button inside `.header` (before the channel name):
```html
<button class="hamburger">☰</button>
```

2. Create a sidebar in your HTML (place it inside `.chat-container` before `.messages`):
```html
<div class="sidebar">
    <div class="sidebar-item"># General</div>
    <div class="sidebar-item"># Random</div>
    <div class="sidebar-item"># Tech</div>
</div>
```

3. Add a backdrop (place it right after `.chat-container`, outside it):
```html
<div class="sidebar-backdrop"></div>
```

4. In `styles.css`, define the base styles:
```css
.hamburger {
    display: none; /* Hidden on desktop */
    background: none;
    border: none;
    color: white;
    font-size: 24px;
    cursor: pointer;
}

.sidebar {
    width: 200px;
    background: var(--bg-secondary);
    padding: 20px;
    display: flex;
    flex-direction: column;
    gap: 10px;
}

.sidebar-item {
    color: var(--text-secondary);
    padding: 10px;
    border-radius: 8px;
    cursor: pointer;
}
.sidebar-item:hover {
    background: var(--bg-header);
}

.sidebar-backdrop {
    display: none; /* Hidden by default */
}
```

5. Inside `@media (max-width: 768px)`, write the mobile CSS:
```css
@media (max-width: 768px) {
    .hamburger {
        display: block;
    }

    .chat-container {
        width: 100%;
        height: 100vh;
        max-width: 100%;
        border-radius: 0;
    }

    .sidebar {
        position: fixed;
        top: 0;
        left: 0;
        height: 100%;
        width: 75%;
        max-width: 300px;
        transform: translateX(-100%);
        transition: transform 0.3s ease;
        z-index: 100;
        background: var(--bg-secondary);
        padding-top: 60px;
    }

    .sidebar-open {
        transform: translateX(0);
    }

    .sidebar-backdrop {
        display: block;
        position: fixed;
        inset: 0;
        background: rgba(0, 0, 0, 0.5);
        z-index: 99;
        opacity: 0;
        pointer-events: none;
        transition: opacity 0.3s ease;
    }

    .sidebar-open + .sidebar-backdrop,
    .sidebar-open ~ .sidebar-backdrop {
        opacity: 1;
        pointer-events: all;
    }
}
```

6. **Manual test:** In DevTools, set the viewport to mobile size (< 768px). Add the class `sidebar-open` to the sidebar element manually in the Elements panel. The sidebar should slide in.

**Verification (MANDATORY):**
- [ ] On desktop (> 768px), sidebar is visible and hamburger is hidden.
- [ ] On mobile (< 768px), hamburger appears and chat takes the full screen.
- [ ] Manually toggling `.sidebar-open` in DevTools slides the sidebar in/out smoothly.
- [ ] A backdrop appears behind the sidebar when `.sidebar-open` is added.

**If this fails →** Check your CSS selector order (`.sidebar-open ~ .sidebar-backdrop` requires the backdrop to come after the sidebar in HTML).  
**If this passes →** **VERSION 1 IS COMPLETE.**

## Debugging Tips for This Stage

| Problem | Likely Fix |
| :--- | :--- |
| Bubbles not aligning left/right | Check `align-self` on `.message.sent` and `.message.received`. Ensure `.messages` has `display: flex` + `flex-direction: column`. |
| Input/button not aligned | Ensure `.input-area` has `display: flex` and `align-items: center`. |
| Scrollbar not showing | Ensure `.messages` has a fixed `height` or `flex: 1` inside a container with fixed height. |
| Sidebar doesn't slide | Check `transform: translateX(-100%)` on base and `transform: translateX(0)` on `.sidebar-open`. Ensure `transition` is on the base rule. |
| Backdrop not showing | The backdrop must come **after** the sidebar in HTML. Use sibling selectors (`.sidebar-open ~ .sidebar-backdrop`). |
